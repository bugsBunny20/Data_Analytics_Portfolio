### 2. Python Fundamentals Capstone

**Goal:** To apply Python programming fundamentals and data manipulation techniques to combine, transform, and analyze project and employee datasets.

**Description:**

This project is based on a Python Fundamentals capstone assignment involving three datasets: project details, employee information, and employee designation levels.

The assignment focuses on creating DataFrames, saving datasets as CSV files, handling missing values, manipulating columns, combining datasets, and performing conditional operations.

The project also involves calculating employee bonuses for completed projects, adjusting designation levels based on project status and employee age, and calculating the total project cost associated with each employee.

**Key Tasks:**

- Create three Pandas DataFrames and export them as CSV files.
- Handle missing project costs using a running average calculated with a `for` loop.
- Split employee names into first-name and last-name columns.
- Merge the project, employee, and designation datasets into a single DataFrame.
- Calculate a 5% bonus on project costs for completed projects.
- Adjust employee designation levels based on failed projects.
- Apply conditional designation changes based on employee age.
- Calculate the total cost of projects associated with each employee.
- Filter employee records based on their city names.

**Skills:** Data manipulation, missing-value handling, conditional logic, loops, DataFrame operations, dataset merging, and aggregation.

**Technology:** Python, Pandas, NumPy.

**Results:** The assignment provides practical experience in transforming related datasets and applying programming logic to solve data-processing problems. Specific outputs and findings can be documented alongside the completed notebook.
